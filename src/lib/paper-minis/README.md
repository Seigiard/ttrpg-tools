# Paper minis

The image, size, packing and PDF modules and their tests come from
[Seigiard/printableminimaker](https://github.com/Seigiard/printableminimaker).
The original MIT notice is preserved in
[`public/paper-minis-LICENSE.txt`](../../../public/paper-minis-LICENSE.txt),
which is also served with the site.

References to `printableminimaker ADR-0002` refer to the source project's
[architecture decisions](https://github.com/Seigiard/printableminimaker/tree/main/docs/adr).
References to `printableminimaker#24` refer to its
[graded-height issue](https://github.com/Seigiard/printableminimaker/issues/24).
