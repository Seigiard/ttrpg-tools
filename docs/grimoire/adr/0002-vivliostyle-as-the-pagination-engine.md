# Vivliostyle paginates the book

Browsers do not support every paged-media feature Grimoire needs, including `string-set`
and `target-counter()`. Paged.js has unresolved multi-column defects and can duplicate
margin boxes during browser printing. Vivliostyle therefore owns pagination.

The dependency is AGPL-3.0. TTRPG Tools is open source, so offering source to network
users is compatible with the product. Reconsider the engine if the application ever
becomes closed source or grows into long books where Vivliostyle's table-of-contents
performance becomes material.
