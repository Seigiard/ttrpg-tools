# The base stylesheet is copied, not depended on

The default theme starts from magick.css. It is copied under its MIT license and edited
locally because the upstream sheet has no print support, uses Latin-only remote fonts,
and exposes too little of its layout as variables to override cleanly.

We own updates to the stylesheet. Its fonts are self-hosted and bundled under the SIL
Open Font License; their license travels with the font files.
