# TTRPG Tools

TTRPG Tools is the host and catalogue for browser-based tabletop role-playing tools.

## Language

**Reference table**:
The full rulebook table shown next to a roll's result, with the rolled row (or cell) marked, so the player sees the result in the context of every possible outcome. In Russian UI and docs: «справочная таблица».
_Avoid_: lookup table, results list
